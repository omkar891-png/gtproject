    ⚠️ CANNOT REACH GAME SERVER

    Could not connect to the local game server.

    💡 How to Fix & Play Multiplayer:

    1. Start Server on Laptop: In this folder, run npm start in terminal.
    2. Same Wi-Fi / Hotspot: Ensure all phones and laptop are on the same Wi-Fi or phone hotspot (Mobile Data can be OFF!).
    3. Host IP: If playing on a phone, make sure the host IP matches the laptop below.

    ⚙️ CONFIGURE HOST SERVER IP

    If you are playing on a phone browser or app, enter the local IP address of the laptop running the game server.

    Common Addresses:

    • Laptop on Wi-Fi: 192.168.1.102:3000
    • Phone Hotspot: 192.168.43.x:3000
    • Same Machine: localhost:3000

    HOW TO PLAY 100% OFFLINE

    Method A: Mobile Hotspot (No Mobile Data Needed)

    1. Turn on Portable Wi-Fi Hotspot on any one phone (mobile data can be turned OFF!).
    2. Connect your laptop and all friends' phones to that Wi-Fi hotspot.
    3. Open this game on your laptop. Click "Connect Phones" and have friends scan the QR Code!

    Method B: Home Wi-Fi Router (No Internet Needed)

    1. Connect your laptop and phones to the same Wi-Fi router.
    2. Even if the internet connection is down, local multiplayer will work flawlessly at ultra-fast speeds!
